# FinPilot

**Autor:** osacra

FinPilot é uma plataforma web de gestão financeira multi-tenant para organizações. O projeto está sendo desenvolvido com React, TypeScript, Tailwind CSS, Express, tRPC, Drizzle ORM e MySQL/TiDB.

## Direção do produto

A plataforma terá organizações isoladas, membros com papéis distintos, contas financeiras, categorias, transações, dashboard, relatórios, importação e exportação CSV e histórico de auditoria.

## Direção visual

A interface seguirá uma estética industrial moderna com hierarquia brutalista, composição geométrica e identidade principal restrita à escala de cinzas.

## Desenvolvimento

A evolução é feita localmente em ciclos verificáveis. Cada marco deve passar por typecheck, testes automatizados e validação no preview antes de ser registrado em um commit de autoria `osacra` e sincronizado com o repositório privado no GitHub.
